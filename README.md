# 变电站继电保护定值整定与二次设备检修管理平台

面向变电站台账、保护装置、定值整定与核对、二次回路检查、保护校验、故障录波分析、主变检修与直流系统监测的一体化电网二次设备运维管理工作台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `substation-protection:entries` 这一项，或调用 `resetModule(模块)`。

## 保护校验的归属与锁定规则

保护校验（`relaytest`）的业务规则集中在 `frontend/src/api/relay-test-service.ts`，页面只读取与转发：

- **按班组归属**：每条校验记录有「所属班组」，动作值与返回值只有归属班组能改，跨班组修改一律打回；
  顶栏可切换值班班组与经办人用于验证。
- **不合格锁定**：判过「校验不合格」的整条记录锁成只读，不能直接改数值翻案；须由本班组「重做校验」，
  轮次加一后重新判定。
- **列表只读、单一数据源**：列表只能查看，所有写入只改 localStorage 里的同一行；明细面板、名册、
  导出都按同一字段读取，重新进入仍是同一份，不会换一份。
- **改动留痕**：动作值/返回值修改与状态流转都记录时间、经办人、班组、原值与新值，经办人不留空。
- **导出对齐**：导出册子显式输出动作值、返回值等固定列（并做 CSV 转义），与明细逐格一致，不丢列。
- **复核联动**：判不合格会向二次回路检查写入一条「待复核」清单，同一条只生成一份（幂等），
  在二次回路检查页可受理复核；翻案合格时自动闭环。
- **提交幂等**：同一条记录在「校验中」重复提交校验只算一遍，不增加轮次、不重复留痕。
- **兼容旧数据**：没有所属班组/经办人/留痕字段的既有校验记录，读取时自动补齐默认归属（继电保护一班）。
